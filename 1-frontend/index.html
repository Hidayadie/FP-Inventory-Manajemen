Fitur Utama

Solusi Terpadu Pengelolaan Inventaris

Dirancang untuk meminimalisir aset yang hilang, mempermudah pelacakan inventaris fisik, dan mempercepat respons terhadap kendala operasional.

Manajemen Aset

Pendataan lengkap aset mulai dari nomor seri, nama item, kategori barang, hingga status ketersediaan barang.

Lokasi & Kategori

Kelola ruangan, gedung, dan klasifikasi jenis aset agar pencarian inventaris menjadi sangat mudah dan terorganisir.

Tiket Komplain

Pengguna dapat melaporkan aset rusak atau masalah fasilitas secara langsung dengan status penanganan yang transparan.

Portal Teknisi

Teknisi dapat melihat daftar tiket perbaikan yang ditugaskan dan memperbarui status pengerjaan secara real-time.

Akses Berbasis Peran

Dirancang untuk Tiga Peran Utama

Sistem membatasi hak akses berdasarkan role yang terverifikasi aman melalui token otentikasi.

Administrator

Pengelola Penuh Sistem
  • Mengelola master data Kategori & Lokasi fisik.
  • Menambah, mengedit, dan menghapus data Aset.
  • Melihat statistik dashboard dan riwayat komplain.
  • Mendisposisi tiket perbaikan ke teknisi.

Struktur Akses & Port Server

Proyek ini memisahkan layer Backend (Go Gin) dan Frontend (Web Client) secara rapi. Jika Anda atau penguji menjalankan aplikasi, pastikan kedua service berjalan pada port yang sesuai:

Backend REST API (Go Gin)
Berjalan di: http://localhost:8080
Menyediakan endpoint autentikasi, manajemen aset, kategori, lokasi, dan dashboard.
Frontend Web Client
Berjalan di: http://localhost:8081
Halaman statis yang terhubung melalui CORS ke backend port 8080.
Petunjuk Menjalankan Proyek Terminal Bash
# 1. Jalankan Backend (Go Gin)
cd 2-auth
go run main.go
✓ Server berjalan di http://localhost:8080
# 2. Jalankan Frontend Web Server (Port 8081)
cd 1-frontend
http-server .
✓ Buka di browser: http://localhost:8081
Tips Cepat: Kini Anda dapat langsung membuka http://localhost:8081 tanpa perlu repot mengetik /login secara manual.
